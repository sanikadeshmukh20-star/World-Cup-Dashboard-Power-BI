# 🏆 World Cup Analysis Dashboard – Power BI

## 📌 Project Overview
This project presents an interactive World Cup Analysis Dashboard created using Microsoft Power BI. It provides insights into World Cup matches, team performances, player statistics, and tournament results through interactive data visualizations.

## 🎯 Objectives
- Analyze World Cup match statistics.
- Explore team performance and winning records.
- Understand player performance and contributions.
- Visualize tournament trends and results.
- Present meaningful insights using interactive dashboards.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📊 Dashboard Features
- Interactive charts and graphs.
- World Cup statistics and match analysis.
- Team performance insights.
- Player statistics.
- Tournament result analysis.

## 📁 Project Files
- `.pbix` – Power BI dashboard file.
- `README.md` – Project documentation.
- Dashboard screenshots – Visual representation of the report.

## 🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the interactive dashboard and visualizations.
